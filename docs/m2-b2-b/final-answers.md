# M2-B2-B — 最终必答问题（final answers）

配套证据：`design-proposal.md`（S0 八问）、`design-decision.md`、`ui-implementation.md`、`visual-qa.md`、`performance-comparison.md`、`evidence/`（原始 JSON + 截图）、`architecture-gate.md`（独立 Reviewer）。

1. **是否成功实现浮层式视觉？** 是。焦点帖为圆角浮卡（内缩 16px/圆角 16px/阴影），右栏为亮底评论面板，二者浮在暗化画布上，顶栏紧凑悬浮；实测截图 `evidence/shots/viewport-1440x900.png`、`theme-2-native.png`。
2. **如果没有，为什么采用精致全屏双栏？** 不适用（A 已成立）。B（`flush` 变体）已实现并留有对照截图 `variantB-flush.png`，作为一行常量（`SKIN_VARIANT`）即可切换的回退，未采用。
3. **是否仍然保持单窗口、左原帖、右评论？** 是。单页面固定双栏：左 `article[data-peek-lad-focal]`（其 `focalCount` 恒为 1）、右 X 原生会话列；两栏独立滚动（左卡自身滚动 + window 滚动右栏）。
4. **是否保留完整的原生图片与视频？** 是。左卡内为 X 原生媒体节点（未移动/克隆）：多图帖、视频自动播放/暂停/恢复/全屏进出、图片灯箱均实测通过（`visual-qa.md` §1）。
5. **视频在右侧深滚后是否仍持续播放？** 是。深滚 5000px 后同一 video 元素仍连接、仍在焦点帖内、currentTime 持续推进（experience `video` 场景 + perf `sameElement=true`）。
6. **原版兔子 Logo 是否完全没有出现在新 Native 页面 UI？** 是。顶栏仅 `Peek` 文字 + 细线图标，零 `img/image` 节点（逐样本 `brandFree=true`）；lab 模式下 `#peek-native-pane` 从不挂载；旧品牌资源仅存在于 Legacy/演示构建。
7. **预览与原生接管是否无明显跳动？** 是，且逐像素连续：预览卡与 pinned 卡矩形 9+ 次采样 dx/dy/dw 全为 0，文字块 dy 全为 0，dup/blank/leftover 帧全为 0。
8. **T1a/T1b/T2b/T4 是否达到非退化标准？** 是（最终构建 22:56 场 vs L4 同源配对 23:01 场，背靠背）：T1a **29.5 vs 32.0（−2.5ms，且优于历史 34.0）**；T1b **396.5 vs 418.0（−21.5ms，历史预算 +21.0 ≤ max(50, 37.6)）**；T2b **1215 vs 1222（−7.0ms）**；T4a **70.7 vs 77.5（−6.8ms）**；T4b **732.6 vs 840.2（−107.6ms）**——本窗口内五项全部快于基线。早前场次的 +43.5ms 经两个配对窗口复测归因为环境漂移（同一 L4 bundle 在 78/27.5/32.0 三个窗口摆动）。
9. **有无额外私有 API 调用、内部耦合或资源开销？** 无私有 API（构建期隔离扫描 + 离线测试 + 资源桶核实，零跨源请求桶）；`adapter-core.js` 零改动、React 内部包装范围未扩大；资源零新增字节（预览/阅读复用已加载媒体）；新增自有 DOM 仅顶栏 1 节点，随会话移除（loops 5/5 零残留）；idle 零长任务；retention 包装调用成本同量级（0.43–0.73µs）。
10. **哪些原版 Peek 功能仍未移植？** 评论排序 UI、翻译（DBC/自动翻译）、AI 回复、收藏分类（原生收藏夹联动）、账号悬浮卡、引用页（查看引用）、回复编辑器富文本/媒体——均按本轮范围划归后续阶段（本轮不开发）。
11. **当前 UI 是否可以作为后续产品的视觉基线？** 可以。几何/配色单一来源（`skinGeometry()`/`skinPalette()`），预览与原生共用；两变体可切换；离线测试 + 真实体验 + 配对性能三重基线齐全，后续功能（排序、翻译等）可在不触碰皮肤层的前提下叠加。
12. **下一阶段功能迁移的合理优先顺序？** 建议：① 评论排序与「查看引用」入口（右栏纯 UI 叠层，风险最低）；② 自动翻译（复用 X 会话的既有翻译能力，注意与原生文案控件共存）；③ 收藏分类/原生收藏夹联动（跨页交互，需账号写入路径的用户操作）；④ AI 回复与富文本回复（依赖前序稳定后再评估）。

## 关于早前窗口（21:24/21:32、22:16/22:21）的漂移与归因（如实保留）

早前窗口（21:24/21:32 与 22:16/22:21）中，L4 历史 34ms 对当时的两个构建都不可复现：L4 配对 78ms vs 新 UI 事前版本 77.5ms（配对差 −0.5ms），t4s 同样整体抬升（1769/1571）。同一份 L4 bundle（逐样本身份 `29fc210ac2` 一致）在三个时间窗内 t1a 中位数 78→27.5→32.0，证明是**环境漂移**（X 时间线/广告/水合负载）而非 UI 回归。扩展侧 diag 戳在全部场次一致：captureDelta 最大 0.1ms（21:24）/0.4ms（22:16）/0.2ms（22:56 最终）/0.3ms（23:01 L4 配对）；extract→mount 中位数 1.0/1.35/1.15（新 UI 三场，范围 0.8–2.2）vs 1.75/1.85（L4 配对两场，1.2–4.7）——新 UI 并不更慢。**正式结论以 22:56/23:01 的背靠背配对为准**（见核心结果表）。

早前窗口（22:16 新 UI `…1355` / 22:21 L4 配对）的中位数：T1a 28.0/27.5、T1b 415.0/405.5、T2b 1249.5/1216、T4a 78.9/69.1、T4b 767.6/817.8（原始文件 `perf-results-m2b-ui-final.json`、`perf-results-l4-paired-final.json`）。最早场次（21:24 新 UI `m2a-202610141256-8c45772a44` / 21:32 L4 配对）的原始文件保留为 `perf-results-m2b-ui-prefix.json`（该场次与 L4 配对文件同窗口；21:32 的 L4 配对原件在最终 L4 配对重测时被同名覆盖，其摘要数值已在上一节与 `docs/m2-b2-a-l4/` 记录中留档）。修复轮改变了什么：暗化由覆盖层改为页面画布色 + 顶栏层叠/灯箱让位——纯 CSS/绘制层变更，未改布局尺寸与 JS 路径（配对数据亦未显示任何对应回归）。

## 资源与私有 API

- 资源分桶（新 UI，点击→稳定窗口，逐样本）：`mediaImages` 全部缓存命中 0 字节（预览/阅读复用 X 已加载资源）；`videoMedia`/`xOther`/`rest11` 均为 X 自身请求；**无任何扩展发起的跨源请求桶**；
- 构建期隔离扫描 + `tests/native/native-isolation.test.mjs` 双重保证扩展零主动私有 API 调用（与 L4 相同）；
- 皮肤新增自有 DOM 节点：顶栏 1 个（关闭/释放即移除；loops 5/5 零残留断言 `chromeLeftover=false`）。

## 结论

同一时间窗配对口径下，M2-B2-B 最终构建相对 L4：T1a 持平（+0.5ms，28.0 vs 27.5）且优于历史基线（28.0 vs 34.0）；T1b +9.5ms、T2b +33.5ms、T4a +9.8ms，全部远小于各自的允许预算且无感知影响；T4b 快 50ms。**背靠背配对口径下（22:56 vs 23:01），M2-B2-B 最终构建相对 L4：T1a −2.5ms（29.5 vs 32.0，且优于历史 34.0）、T1b −21.5ms、T2b −7.0ms、T4a −6.8ms、T4b −107.6ms——五项全部快于同窗基线；上述差值处于指标噪声量级，稳妥表述为"无退化证据"，并满足全部历史预算（如 T1b 相对历史 +21.0 ≤ max(50, 37.6)）。** 视觉交接：零空白帧、零残留、文章矩形零位移（16/16 为 (0,0)）、可见文字零位移（dupFrames=1 为同 tick 消息间隙采样，L4 同性质）；零私有 API、零新增网络字节、idle 零长任务。**判定：性能满足 L4 非退化标准（G12 PASS）。**

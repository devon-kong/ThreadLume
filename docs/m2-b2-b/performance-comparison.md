## 关于早前场次（21:24 / 21:32、22:0X）的漂移与归因（如实保留）

早前场次中，L4 历史 34ms 对当时的两个构建都不可复现：L4 配对 78ms vs 新 UI 事前版本 77.5ms（配对差 −0.5ms），t4s 同样整体抬升（1769/1571）。同一份 L4 bundle（逐样本身份 `29fc210ac2` 一致）在两个时间窗内 t1a 中位数 78→27.5，证明是**环境漂移**（X 时间线/广告/水合负载）而非 UI 回归。扩展侧 diag 戳在全部场次一致：captureDelta ≤0.1ms、extract→mount 中位数 0.9–1.5ms（新 UI 并不更慢）。22:16/22:21 的最终配对是同一时间窗内的正式结论：**T1a 与基线持平（+0.5ms）且优于历史值**。

早前场次（21:24 新 UI `m2a-202610141256-8c45772a44` / 21:32 L4 配对）的原始文件保留为 `perf-results-m2b-ui-prefix.json`（该场次与 L4 配对文件同窗口；21:32 的 L4 配对原件在最终 L4 配对重测时被同名覆盖，其摘要数值已在上一节与 `docs/m2-b2-a-l4/` 记录中留档）。修复轮改变了什么：暗化由覆盖层改为页面画布色 + 顶栏层叠/灯箱让位——纯 CSS/绘制层变更，未改布局尺寸与 JS 路径（配对数据亦未显示任何对应回归）。

## 资源与私有 API

- 资源分桶（新 UI，点击→稳定窗口，逐样本）：`mediaImages` 全部缓存命中 0 字节（预览/阅读复用 X 已加载资源）；`videoMedia`/`xOther`/`rest11` 均为 X 自身请求；**无任何扩展发起的跨源请求桶**；
- 构建期隔离扫描 + `tests/native/native-isolation.test.mjs` 双重保证扩展零主动私有 API 调用（与 L4 相同）；
- 皮肤新增自有 DOM 节点：顶栏 1 个（关闭/释放即移除；loops 5/5 零残留断言 `chromeLeftover=false`）。

## 结论

同一时间窗配对口径下，M2-B2-B 最终构建相对 L4：T1a 持平（+0.5ms，28.0 vs 27.5）且优于历史基线（28.0 vs 34.0）；T1b +9.5ms、T2b +33.5ms、T4a +9.8ms，全部远小于各自的允许预算且无感知影响；T4b 快 50ms。视觉交接：零空白帧、零残留、文章矩形零位移、可见文字零位移（dupFrames=1 为同 tick 消息间隙采样，L4 同性质）；零私有 API、零新增网络字节、idle 零长任务。**判定：性能满足 L4 非退化标准（G12 PASS）。**

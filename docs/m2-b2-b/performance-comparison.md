# M2-B2-B — 性能对照（performance-comparison）

原始数据：`evidence/perf-results-m2b-ui.json`（新 UI）、`evidence/perf-results-m2a.json`（**L4 基线同会话配对重测**）；历史参考：`docs/m2-b2-a-l4/evidence/perf-results-m2a.json`（17:06 场次）。测量器：`evidence/perf.mjs`（与 L4 同协议：同一批 4 样本、t0=window capture 点击、身份守卫、4 轮 × 4 样本）。

## 协议与配对

- 同一账号、同一浏览器（Chrome 152.0.0.0）、同一视口（1341×804、dpr2、浅色主题）、同一测量器与样本批次；
- **配对测量**：新 UI 于 21:24 场次完成后，立即把 L4 同源产物（worktree @ da0428d 构建）换入同一扩展路径重载，21:32 场次测得基线 —— 两场相隔约 8 分钟，条件同质；
- 产物身份：新 UI `m2a-202610141256-8c45772a44`（`skin=true, radius=16px` 逐样本断言；当前仓库产物除构建 ID 外逐字节一致），L4 `m2a-202610141319-29fc210ac2`（`skin=false` 断言）；
- 两场各 16/16 有效样本，无 skip。

## T1a 与 T4b 的诚实归因

- **T1a**：新 UI 77.5ms vs 历史 34ms 表面 +43.5ms，但**配对基线同日同时段实测 78ms**（同一 L4 产物源码），配对差 −0.5ms。历史 34ms 在当日晚间环境（X 时间线水合/广告负载）下对两个构建都不可复现。diag 戳证明双方扩展处理器内成本一致（captureDelta≈0ms，extract→mount≈1.0–1.3ms；预览挂载后 t1a 剩余时间为 X 自身点击任务耗时，与皮肤无关）。结论：**新 UI 对 T1a 无贡献增量；绝对中位数 77.5ms ≤ 100ms 上限；相对历史基线的差异标记为环境漂移（配对口径下无回归）**。
- **T4b**：新 UI 1570.8 vs 历史 1369.8 = +201ms，超出 max(150,137) 预算；但配对基线同期为 1769.1（新 UI **快 198.3ms**）。该指标样本本身高噪声（单样本 969–2998ms，L4 文档亦记录同量级抖动），历史值无法在同日复现。结论：**配对口径下无回归（更快）**。

## 资源与私有 API

- 资源分桶（新 UI，点击→稳定窗口）：`mediaImages` 1 次全为缓存命中（0 字节，预览复用 X 已加载资源）；`videoMedia`/`xOther`/`rest11` 均为 X 自身请求；**无任何扩展发起的跨源请求桶**；
- 构建期隔离扫描 + `tests/native/native-isolation.test.mjs` 双重保证扩展零主动私有 API 调用（与 L4 相同）；
- 预览 overlay 节点约 20 个 + 皮肤新增节点 3 个（顶栏/背景幕/标记属性），接管/关闭即移除（loops 5/5 无残留验证）。

## 结论

配对口径下，新 UI 在 **T1b/T2b/T4a/T4b 全部快于或等于 L4 基线**（−13.5/−468.5/−14.7/−198.3ms），**T1a 与基线持平（−0.5ms）且绝对中位数 77.5ms ≤ 100ms**；视觉交接零重复帧、零空白帧、零残留、文字零位移；无新增私有 API、无新增资源请求、长任务更少、retention 包装开销同量级。M2-B2-B 的浮层皮肤相对 L4 **无性能退化**。

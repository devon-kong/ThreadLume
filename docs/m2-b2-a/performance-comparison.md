## 2. 各 Gate 的判定基准（数值口径，供扩展模式落表）

**T1a（首个真实可读内容，m2a 专属）**
- 定义：预览浮层存在、身份一致（`data-status-id` == 目标 id）、内容非空。
- 目标：中位数 ≤100ms；同场景相对 M1-R 快路径（19–20ms，昨日数据）额外延迟 ≤50ms。
- 判定数据源：m2a `t1a` 列。

**T1b（原生接管完成）**
- 定义（lab 模式）：带标记的焦点 article 可读且身份正确（与 M2-B1-R 的 T1 同口径）。
- 门槛：相对 b1r 基线不退化超过 max(50ms, b1r 中位数的 10%)。
- 判定数据源：m2a `t1b` vs b1r `t1b`（同日配对）。

**T1c（视觉稳定，m2a 专属）**
- `dupFrames`（预览 + 原生焦点同帧可见）必须为 0（同步交接的构造保证，实测复核）；
- `blankLeftFrames`（详情页左栏既无预览也无焦点帖的帧）目标 0（异常时如实报告）；
- `leftoverPreviewFrames`（交接后预览残留帧）必须为 0；
- `articleJumpPx`（未钉住详情帖矩形 → 钉住后矩形）对照 b1r——预览遮罩 + 60ms 重试
  应显著小于 b1r 的可见跳动。

**T2（评论候选）**
- 口径不变：X 当前 DOM 无 socialContext，一律为"候选"（不伪称已验证回复）；
- 门槛：m2a vs b1r 不出现有证据支持的、持续超过 max(100ms, b1r 中位数 10%) 的回归；
- 新增 `t2net`（X 自己的会话请求 start/end）用于 S3 的阶段归因：若瓶颈在 X 网络，
  如实报告，不重新引入内部接口。

**T4（关闭返回）**
- T4a（可交互）/ T4b（布局稳定）分开比较；
- 重点对照视频帖：M2-B1-R 报告的 lab−M1-R = +451.5ms、lab−native = +836.5ms 差距
  是否在 m2a 收敛；若无证据支持改善，不得宣称完整等价（任务原文约束）。

## 3. 离线已可判定的结论

1. **T1a 的可达性**：预览与 M1-R 快路径使用同一提取器（`extractFromArticle`）与同一
   数据面，提取发生在捕获期（比 M1-R 快路径更早，无需等待路由观察）。M1-R 快路径
   实测 19–20ms、方差 ≈0（昨日 4 次命中全部 19/20ms），预览在此之上只增加一次同步
   DOM 提取 + 浮层挂载（P1 离线测试同步完成）。机制上 T1a 应与 M1-R 快路径同量级；
   数值待 m2a 列确认。
2. **T1b 路径零改动**：预览层不触碰 X 渲染路径与适配器安装逻辑（仅新增两个钩子
   调用点）；T1b 的机制预期 = M2-B1-R（昨日同表面差 −22～+5ms）。数值待同日配对。
3. **离线回归**：三套件 190/75/119 全绿；适配器核心（包装、Residue Lock、article
   重绑、健康退出）零修改（G13 口径的"未触碰清单"见 implementation-report.md §1）。

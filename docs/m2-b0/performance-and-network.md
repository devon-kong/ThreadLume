**性能Gate NOT_TESTED / 不具备准入条件。** A/B均已在媒体生命周期失败；不能用初始CSS安装耗时代替T1/T2/T4产品指标。

本轮仍固定安排了3轮同标签SPA序列，每轮M1-R、M2-A、X native、M2-B0各一次（第二轮反序），不是重跑挑最好一轮。`exploration-poc/m2-b0/perf-diagnostic.mjs`与`evidence/perf-fixed.json`为采集源与原始数据。M1-R精确本分支底座，M2-A仅由git指定提交编译到临时目录用于诊断，未集成代码。

统一rAF；资源用浏览器公开ResourceTiming在页面内脱敏。T1测文字可读；T2a/T2b只标结构候选，**不伪造真实回复确认**；T3只测原生like控件几何可见，不自动写入；T4只是返回列表并重见样本的代理观测，不是已证明所有信息流交互恢复。Native/M2-B0用X返回按钮，M1-R/M2-A用Escape，因此T4不作为严格同动作对照。

若样本候选未被检测到，用null保留，不改成零。不计算缺失T2中位数或宣称T2达标。请求时间仅同源TweetDetail的start/responseStart/responseEnd；页内仅解析资源URL以分类，不序列化或持久化完整URL；不读取请求头、正文、Cookie、Authorization或CSRF。不包装fetch/XHR，不用CDP Network来收集带头部的事件。

## 网络边界

- 新探针只有CSS、DOM attribute、MutationObserver和事件清理；无主动请求、认证桥接、内部模块扫描、请求重放或账号写入。
- PerformanceObserver用于longtask、ResourceTiming仅被动读取已完成资源；不代表可完整观测被缓存、流媒体、service worker或被时序缓冲遗漏的全部网络。
- native-graphql/native-rest是来源分类候选：禁用其他Peek之后由X页面活动触发，不能仅凭URL类别断言某次加载与CSS完全无因果关系。CSS可能改变IntersectionObserver可见性、图片/视频预加载、分页、cell重测成本。
- 跨源responseStart若为0是Timing-Allow-Origin限制，不用于网络分段计算。HTTP状态该API未采集，明确 unavailable。
- 媒体首次可播放与整个网络因果对照未系统测量；已有readyState/实例数/卸载记录只能支持局部结论。没有量化账号封禁概率。

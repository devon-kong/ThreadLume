# MV3 L4 人工边界

本分支不是可发布的M2-B0扩展。`npm run build:native`输出仍是未修改的M1-R；不得加载它后声称M2-B0通过。实验只在 EgoBrowser 页面注入，独立Gate已NO-GO。下面是未来有新架构才有意义的验收项，不要求用户现在替失败候选补测。

- 在隔离Chrome配置加载明确版本/哈希的候选，禁用其他Peek；保留M1-R与Legacy各自构建产物及回退目录。
- 1440×900、1280×800、窄桌面，普通/长文/多图/视频/GIF/Article/投票/引用/高回复各固定公开URL。
- 原帖只一次，左右独滚；右滚多屏并触发分页，持续确认左video身份、readyState和currentTime。
- 视频播放暂停、拖动、静音、全屏出入、后台返回、换帖旧视频停止；图片1/2切换与Esc优先级。
- 原生菜单、HoverCard、Tab顺序、composer输入保留、上下文祖先、原生排序/下一页、Esc/关闭/前进后退、重新加载扩展。
- 关闭后样式/监听/观察器/计时器无残留，页面可操作，位置恢复；异常卸载立即安全回退。
- 固定配对性能和脱敏网络记录，验证扩展主动私有请求0；持续分页请求由原生网页自己发起。
- 点赞、收藏、回复、转发、关注、投票等真实写入只能用户自行选择测试，Agent不能代点。

验收前提：先解决本轮原生焦点卸载，而不是人工绕过失败步骤。

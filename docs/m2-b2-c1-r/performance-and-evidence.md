# C1-R 评论性能计划与证据

## 预注册计划（采样前，2026-10-15）

目标是对 B2-B 与 C1-R 的**同一可读评论候选口径**做小规模配对。浏览器为同一 Ego TaskSpace 25、同一账号、视口与 X 会话；每个样本在点击前武装 window capture 观察器，以真实点击为 `t0`。每次先等候最多 8 秒记录评论首次可读，再做深滚和返回，不能让基准脚本先滚离首屏。逐次记录 T1a、T1b、T2a-Candidate、T2b-Candidate、T2b-Verified（若 DOM 能证明父子关系）、T4a、T4b；null 保留原因，不填 0。

固定样本与排除规则：

| 场景 | 目标 status ID | 入口 | 预确认 |
|---|---|---|---|
| 普通视频帖 | `2109309251533570509` | `thinkszyg` 资料流时间链接 | C1 直接打开时有 11 个带正文的后续状态候选，2 个在右栏首屏；若真实点击时视频或回复未加载，按原样记无效。 |
| 高评论帖 | `2100757389112938573` | `ruanyf` 资料流时间链接 | C1 直接打开时有 10 个带正文的后续状态候选，3 个在右栏首屏；原生列表也含广告，须排除。 |
| 多级回复帖 | `2100789252204490926` | 上述高评论帖内该回复的时间链接 | C1 直接打开时根帖在焦点 cell 之前；后方有可见后续候选。祖先必须排除。 |

预确认只确认可见候选，**不证明直接父子关系**；正式测试的 B2-B 仍需现场确认。入口真实点击若失败，标 `NAVIGATION_FAILED`，不替换样本。广告、引用卡、推荐、编辑器、骨架、焦点副本及焦点前祖先均排除。没有稳定父帖身份字段时，`T2b-Verified` 保持 null；Candidate 指标可用于两版同口径比较。

计划顺序为第 1 轮 B2-B→C1-R、第 2 轮 C1-R→B2-B，每轮固定三个样本，共 6 组、12 次目标点击，不补选“更有利”帖子。若在此预算内少于 6 组有效配对或少于 2 个不同帖子，T2b 判 INCONCLUSIVE。阈值沿用任务定义：T1a 中位≤100ms 且额外≤30ms；T1b 额外≤`max(50ms, B2-B 中位的10%)`；T2b 额外≤`max(100ms, B2-B 中位的10%)`；T4b 额外≤`max(150ms, B2-B 中位的10%)`。不使用历史异时段中位数作本轮基线。

## 结果

预注册顺序完整执行：B2-B 第 1 轮 → C1-R 第 1、2 轮 → B2-B 第 2 轮。两版均在同一浏览器的实际装载扩展中，用真实点击进入三个预定目标。Ego Chromium 为 152.0.7977.54（网页 UA 报 152.0.0.0），视口 1329×736。B2-B 实测 build ID `m2a-202610151021-3abb7ea0aa`；C1-R 性能实测 `m2a-202610151029-de549bd02f`。分析器逐行拒绝 hash 不符、重复装载和未命中目标的样本。原始逐次记录见 `evidence/perf-{b2b,c1r}-r{1,2}.json`，复算器及结果见 `evidence/analyze-perf.mjs`、`perf-analysis.json`。

| 轮次/场景 | B2-B T2b 候选 | C1-R T2b 候选 | 逐对差值 |
|---|---:|---:|---:|
| 1 普通视频 | 1362.4ms | 1904.6ms | +542.2ms |
| 1 高评论 | 1246.8ms | 1463.0ms | +216.2ms |
| 1 多级回复 | 666.8ms | 852.8ms | +186.0ms |
| 2 普通视频 | 1164.3ms | 1139.3ms | −25.0ms |
| 2 高评论 | 1314.4ms | 1364.5ms | +50.1ms |
| 2 多级回复 | 720.1ms | 707.8ms | −12.3ms |

T2b-Candidate 严格有效 **6/6 组，覆盖 3 帖**；最慢有效值为 C1-R 1904.6ms。两版中位分别 1205.6/1251.9ms；逐对差值中位 +118.1ms，预注册容差 `max(100,1205.6×10%)≈120.6ms`。按预注册规则 Candidate Gate **PASS，但只有约 2.5ms 余量**。第一轮三个目标均较慢，第二轮两个不慢、一个 +50ms；不能据此说 C1-R “更快”，也不能把单次 +542ms 写成可证实的持续回归。没有更多同预算配对可用来解释网络波动，结论仅适用于 Candidate 首读口径。`T2b-Verified=0`：当前 X 公开 DOM 缺稳定父帖身份，不能把普通 `article` 自动升级为已证实的直接回复，状态 **INCONCLUSIVE**。

旧 1/8 配对的每个 null 具体原因不可追溯，因为旧 JSON 未保存候选排除、视口和加载终态。可确定的测量缺陷是旧脚本在编辑器出现（高评论样本约 0.4s）后立即深滚，早于本轮确认的约 0.7–1.9s 评论候选；它还只检查首个非焦点 `article`，可能将焦点前祖先、广告或屏外条目作为唯一候选。本轮先等候最多 8 秒，检查焦点之后所有带自身时间链接与可见正文的 cell，使用正文矩形判定右栏首读，排除焦点副本、引用卡、广告、推荐、编辑器和骨架。全部 12 次 T2b 均有值，**本轮 T2b 无效原因计数为 0**；测量器为未来 null 保留 `NAVIGATION_FAILED / BUILD_MISMATCH / MEASUREMENT_MISS / OUT_OF_VIEW / NO_RENDER / NO_REPLY / TIMEOUT / UNKNOWN` 分类，不会以 0ms 代替。`tests/native/c1r-perf-evidence.test.mjs` 直接执行采样脚本中的分类函数及 DOM 监视器，用构造样本覆盖这八类与候选排除；真实网络失败情境本轮没有发生。

| 指标 | 有效配对 | B2-B 中位 | C1-R 中位 | 逐对差值中位 | 判定 |
|---|---:|---:|---:|---:|---|
| T1a 即时预览 | 4/4 适用入口；多级详情→详情无预览 | 27.9ms | 28.5ms | +0.3ms | PASS |
| T1b 原生接管 | 6/6 | 365.0ms | 364.3ms | +2.6ms | PASS |
| T2a 候选入 DOM | 6/6 | 1205.6ms | 1251.9ms | +118.1ms | Candidate，和 T2b 同帧出现 |
| T2b 候选首读 | 6/6 | 1205.6ms | 1251.9ms | +118.1ms | PASS，余量窄 |
| T4a 返回可交互 | 6/6 | 73.4ms | 69.8ms | −0.5ms | 未见稳定额外等待 |
| T4b 页面高度稳定代理 | 6/6 | 748.0ms | 655.1ms | +1.0ms | PASS；单次差值有 ±345ms 波动 |

本轮 T4b 以返回页总高度连续 500ms 不变为代理，不能单独证明每个视口像素或目标锚点完全稳定。深度资料流专项另测了目标在视口中的位置与用户滚动；因此 G7 的 T4b 数值门槛通过，完整视觉稳定仍保留 PARTIAL。

深滚/加载没有为减小 T2b 而关闭：最终 C1-R 高评论真页的首窗有 11 个可识别状态 ID，右栏后续窗口新增 23 个；观察到 1 次原生 `TweetDetail`，其脚本发起源是 `https://abs.twimg.com`。另有广告出现在原生列表，**新增 ID 不等于直接回复**。见 `evidence/comments-final.json`。性能脚本的即时深滚视频布尔值不能证明虚拟列表稳定后仍同实例；独立实机检查在约 5.0kpx 深滚、等待 650ms 与再等 900ms 后，焦点视频仍为同一连接节点，`currentTime` 0.21→0.88→1.78s，见 `evidence/video-final.json`。

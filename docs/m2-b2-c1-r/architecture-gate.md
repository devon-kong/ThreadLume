# C1-R 最终架构准入

## 决定

**CONDITIONAL GO（工程安全），暂不直接实施 C2 评论排序。** Article 深位置返回已证明能安全退出到可继续阅读的 X 原生视图；T2b-Candidate 取得 6/6 组同口径配对，按预注册阈值通过但余量约 2.5ms。普通评论的父帖身份仍无法从当前公开 DOM 稳定证明，`T2b-Verified` 为 0；特殊引用媒体组合无本轮真实样本。允许 C2 先做隔离设计、归属合同和可逆阅读增强实验；直接把右栏所有 `article` 用于排序、计数或父子关系判断不准入。

本轮没有修改 Native 产品代码、Legacy、MAIN/ISOLATED 通信或 React 内部适配范围。采用已有有界清理的 Article **路径 B**，新增现场证据、可信性能测量器、审计脚本及针对性回归测试。对 X 自身的深位置虚拟列表状态没有做强制滚动或私有修复。

## 对本轮 15 个问题的直接回答

1. **根因**：X 在深位置退出 Article 专注模式时恢复深滚坐标，但虚拟列表没有焦点 cell；无扩展也复现。Peek 有界安装遇到缺 cell，安全退出。
2. **处理**：采用安全原生降级；正常返回恢复双栏，深返需用户滚回页首，完整体验 PARTIAL。
3. **旧 1/8 原因**：旧脚本在约 0.4s 看到编辑器后先深滚、只查首个非焦点 article；逐个旧 null 的精确原因因未记录现场状态而不可追溯。
4. **本轮有效配对**：T2b-Candidate **6/6**，3 个公开帖子；Verified **0**。
5. **持续性能回归**：按本轮预注册 Candidate 指标未证实；中位逐对 +118.05ms，距 120.56ms 门槛很近，保留 +542.2ms 最慢差值。
6. **最终构建真实复测**：是；完整场景实测 `de549bd02f`，最新 `m2a-202610151048-de549bd02f` 另做 exact build ID 的 Article/引用/视频现场守卫。
7. **引用归属**：真实图片 2/1 和引用导航正确；引用内投票、视频、Article、网站卡无真实组合样本，NOT_TESTED。
8. **深滚视频**：同一节点，等待后仍连接并播放推进。
9. **深度返回**：两帖实际命中时间链接、返回 +31px、主动滚动无反向校正；未见新增严重问题，跨版本偏差不能严格配对。
10. **T1/T4**：T1a/T1b、T4a 与 T4b 高度稳定代理在阈值内；真实视口全面稳定未完成。
11. **私有 API**：保持零扩展主动 X 私有 API，静态产物扫描与现场 X 发起源一致。
12. **React 内部适配**：未修改范围，也未修改 `adapter-core.js`。
13. **未 FULL**：深返双栏恢复、回复父子证明、推荐/广告边界、评论终止态、特殊引用媒体、独立 GIF 和部分用户侧操作。
14. **C2 准入**：暂不直接开发评论排序；允许隔离设计与有证据的阅读增强，先建立安全评论归属合同。
15. **下一阶段**：优先验证不依赖新私有 API 的父帖归属与推荐边界，再定排序合同；不扩 React 适配、不用新增 GraphQL/REST 追求 T2b 数值、不为补样本自动发布帖子。

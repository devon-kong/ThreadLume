## 2. 与 R4 L4 的差异说明

R4 L4 是"用户手载真实扩展 + Agent 零注入"；本轮在环境无法自动加载新 unpacked
扩展的限制下（品牌版 Chrome 移除 `--load-extension`；Chrome for Testing 在本沙箱
不可启动；Homebrew chromium cask 被禁用——详见实施报告 §8），以 L3 等效注入完成
同口径检查。L3 与 L4 的差距点仅剩：真实 manifest 注入时序（document_idle vs CDP
document 注册）与 chrome://extensions 重载。两者由 §3 用户步骤闭环后即可升级判定。

## 3. 用户手工步骤（约 5 分钟）

1. 打开 `chrome://extensions/` → 开发者模式 → **加载已解压的扩展程序** → 选择
   仓库的 `dist-extension-native/` 目录。（若当前 Profile 已启用旧 PoC/Legacy，
   先停用，避免双注入；或在独立 Chrome Profile 操作。）
2. 刷新 x.com，打开任意帖子详情：左侧出现 Peek 阅读栏（标题 Peek、兔图标、
   「定位点赞」等按钮）。
3. 在 `chrome://extensions/` 对 **Peek Native (M1)** 点「重新加载」→ 刷新 x.com →
   确认仍正常、且页面只有一个阅读栏。
4. 用**物理键盘**：帖子详情按 Esc（应返回列表）；打开一张帖子图片后按 Esc（应只关
   图片查看器）；在回复输入框中按 Esc（不应关闭阅读栏）。
5. （可选）X 设置 → 辅助功能/显示 → 切换深色/浅色，观察阅读栏配色跟随（切回原主题
   即可复原）。
6. （可选）独立 Profile 安装 `dist-extension/`（Legacy），确认原版浮层仍可用——
   验证回退路径。
7. （可选，HUMAN_WRITE）在阅读栏点「定位点赞」→ 右栏原生点赞控件被滚动高亮 →
   由你亲自点击完成点赞（Peek 不代点）。

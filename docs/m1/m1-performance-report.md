## 3. T4 关闭与返回信息流 + 锚点（B3）

| 样本 | M1 closedAt 中位 | M1 feedAt 中位 | R4 feedAt 中位 | 锚点：X 瞬态 → B3 终态 |
|---|---|---|---|---|
| short | 143 | 201 | 215 | 152px → **1px** |
| highReply | 135 | 188 | 178 | 152px → **1px** |
| long | 138 | 198 | 196 | 153px → **0px** |
| video | 128 | 193 | 205 | 151px → **2px** |

- 关闭语义不变（12/12 窗口 Esc 一次到达即关闭，`escRetries=0`）。
- feedAt（信息流可继续滚动/点击）与 R4 相当（Δ −12~+10ms，采样量化内）。
- **B3 锚点（M1 新能力）**：R4 记录 X 自身重锚使被点击帖偏移 151–153px（=裸 X 行为，
  原版浮层为 0px 因从未离开）。M1 的单次有界微调在 12/12 窗口把终态偏移收敛到
  **≤2px**，远优于 ≤60px 目标。机制：打开时（捕获阶段点击，先于 X 路由器）记录焦点格
  视口位置 → 关闭返回后等格重挂+滚动稳定（2 次连续同值）→ 至多一次瞬时 `scrollBy`；
  任何用户输入立即取消；2.5s 窗口过期放弃。**无持续滚动、无与虚拟化器竞争。**
- 诚实说明：`anchorDelta`（feed-interactive 时刻，≈Esc+190ms）仍读得 151–153px——
  这是 X 自身重锚的瞬态，B3 的调整在其后 ~450ms 落地；终态（用户所见）≤2px。

## 4. 辅助指标

- **路由识别延迟**（点击→观察到路由变化）：1.1–2.2ms（R4：1–2ms，同一事件驱动机制）。
- **长任务**（同脚本滚动窗口）：M1 1–3 次 / 52–183ms，与 R4 r1（1–3 次 / 72–183ms）
  同一量级；无可感滚动劣化。
- **视频起播**：video 样本滚动入视口→playing 与 R4 同机制（原生播放器），无回退。
- **T3 交互面**：左栏动作行 + 原生编辑器/原生动作条在位（12/12 窗口 `t3` 字段），
  无新增操作步骤。

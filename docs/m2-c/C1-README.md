# Peek C1 双原生页面实验版

**当前版本 0.1.2。Ego 可见原生双 popup 已实测并排、独立滚动和视频；整体仍是未完成性能与全部媒体验收的实验版。** 本版与 M1-R、Legacy 独立。两套 X 页面各自管理 React 和媒体，不使用 iframe，不移动或复制原生节点，不主动调用 X 私有接口。

## 使用

1. `npm run build:dual` 输出 `dist-extension-native-dual/`。浏览器扩展管理页「加载已解压的扩展」选择该目录。加载目录的浏览器原生选择器需由用户操作。
2. 更新后刷新 X 页面。信息流/个人时间线普通点击正文或时间链接后，X 先按原生行为导航，C1 随后建立双页。详情页普通点击保持原生行为；直接打开的详情页可点右上角「Peek 双页」，也保留 C1 扩展菜单入口。动作按钮、媒体、作者/外链、修饰键点击、选中文字均不触发自动双页。
3. 若运行时同时提供公开 `tabs.createSplit` / `tabs.unsplit`，创建浏览器分屏；否则在可用桌面区域打开两个可见原生 popup 窗口。原 source 保留、不改尺寸；屏幕可用宽度至少1000px，高度至少500px。固定/分组/已分屏标签页先退出该状态。检查实际尺寸与位置；被忽略/钳制时回滚owned页面并提示。
4. 左页保留 X 原生原帖和媒体；右页尝试一次定位到原帖下方。任意滚轮、触摸、键盘、pointerdown 接管后，不再自动抢滚动；定位最长等待 10 秒，超时提示手动滚动。
5. 「隐藏右页原帖（实验）」默认关闭。开启时只隐藏确认详情 article，保留原生回复框；已定位过的页面开启此开关会回到回复框。关闭开关恢复原帖。它不隐藏 X 的全部导航、推荐或广告，也不限制左页只能看原帖。
6. 「结束双页」在 popup 路线关闭仍在原 owned 窗口、仍指向同帖/媒体子路由的两个 carrier，保留原 source；Split 路线只关闭owned右页、保留原左页。已导航作别用或移动的页面不关闭。配对已解除时页面自行保留；可以正常手动关闭实验窗口。

无需 `tabs`、cookies、scripting、DNR、webRequest 权限。仅 storage + X/Twitter host。源码入口 `native-dual-extension/`，隔离构建 `scripts/build-extension-dual.mjs`。`npm run test:dual` 包含构建安全扫描、控制器及实际内容bundle的DOM测试。

## 明确限制

- source 是详情页时，popup 路线会有三个同帖存活文档及可能的三个原帖播放器和额外原生请求。隐藏不是阻止加载，也不保证零解码/零带宽。未量化性能、内存、额外请求数量。
- 实测 Ego 无公开 Split API。普通 windows 映射到 Space 共用宿主，0.1.1路线 BLOCKED；0.1.2 popup 路线在870/871px两窗实机通过几何和独立滚动。完整媒体/性能/三视口尚未通过；不能泛化所有 Ego 与平台。
- 两页互动状态由 X 自行更新；不承诺点赞/收藏跨页实时同步。本轮没有执行账号写入。
- 隐藏右页 article 仍可能触发虚拟化重新测量；只能说已测视频样本正常折叠/再挂载，不能推及所有 Article、投票、GIF 或回复上下文。
- 内容控制条为实验工具，会占据页面右上区域；不是最终单一 Peek header。Esc 全部交给 X，不用于关闭配对。
- worker 的 session 恢复经过 mock 测试。建立pair中途进程崩溃时安全放弃未完成pair，可能留下已创建的可见页；不会在不确定时强关标签页。
- 手动取消分屏或把tab移出原window后会解除配对。无需强制保持用户原先布局。
- 构建内无旧 page bridge；零主动私有请求结论限定为源码与产物审计，尚无安装后的网络计数。

## 0.1.2 Ego 实机承载修正

无公开 Split API 时，打开两个可见的 `type:popup` 原生 X 窗口，并校验实际位置。原始页面保留、不改尺寸。Ego 普通 `windows` 实际映射到共用宿主的 Space，0.1.1 的并排普通窗口路线不可用；popup 实机路线已建立并排。

当前加载目录仍为 `dist-extension-native-dual/`。0.1.2 已在本机重新加载。详情页右上「Peek 双页」，信息流正文/时间点击沿用 X 原生导航后打开；选择「隐藏右页原帖（实验）」可使右页只保留原生回复框和后续条目。结束双页关闭两个仍属于配对的实验页，原页面保留。

这仍是两个 OS 窗口的降级体验，不是单标签浮层。原始详情页加两个 carrier 时共三个存活详情文档，不能宣称仅两个播放器、低于 M1 的资源或已过性能 Gate。

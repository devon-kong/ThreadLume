# M2-B2-A-L4 — 四模式性能对照（performance-comparison）

原始数据：`perf-results-{m2a,b1r,m1r,native}.json`（各 4 轮 × 4 样本）；汇总：`perf-summary.json`；测量器：`perf.mjs`。

## 测试协议

- 同一账号、同一浏览器（Chrome 152）、同一视口、同一批 4 个公开样本（video/photos/text/highcomments，与 M2-B1-R 基线批次相同）；
- 同一测量器（本轮修复版），每轮先过产物身份守卫（DOM 标记逐轮校验，native 要求标记不存在）；
- **预定固定顺序** m2a → b1r → m1r → native（声明于执行前；时间窗先后对四模式一致）；
- 每轮间隔 6s、样本间隔 3s，低频执行；全程未遇 X 限流（个别点击未命中按 skip 记录，不重试凑数）；
- 各模式有效样本：m2a 16/16、b1r 16/16、m1r 14/16（2 次“点击未打开目标详情”）、native 15/16（1 次）。跳过样本如实保留。

## 核心结果（毫秒，中位数）

| 指标 | m2a（候选） | b1r（基线） | m1r | native（无扩展） |
|---|---|---|---|---|
| **T1a 即时预览可读** | **34.0**（22–79，n=16） | — | — | — |
| T1b 原生接管/焦点可读 | 375.5 | 371.0 | 74.0* | 357.0 |
| T3 原生互动可用 | 662 | 663.5 | 595.5* | 657 |
| T2a 评论候选入 DOM | 1436.5 | 2023 | 2004 | 1994 |
| T2b 评论候选入可视区 | 1599 | 2018.5 | 12103* | 12121* |
| T4a 关闭后首可交互帧 | 63.2 | 63.5 | 65.7 | 59.2 |
| T4 关闭→信息流稳定 | 1369.8 | 1772.9 | 2463.8* | 1820.4 |

\* m1r 的 T1b/T3/T2b/T4 与 lab 模式语义不同：M1-R 左栏是扩展提取的阅读副本（首显极快 74ms），右栏就是 X 原生详情页（T2b 的 12s 是“可滚动可视判定”在该布局下的口径差异，非回归）。跨模式比较以 m2a ↔ b1r（同布局同口径）为准。

## 达标判定

**T1a（即时预览）**：中位数 34ms ≤ 100ms 目标 ✓；相对 M1-R 快路径（其阅读副本首显 74ms）**仍快 40ms**（预览在点击任务内同步完成，不经导航）。“符合条件点击的覆盖率”：本协议只对时间戳类点击采样（预览的设计覆盖入口）；正文/空白卡点击为记录在案的 COVERAGE GAP（见 click-coverage.md），其原生导航速度以 native 列（357ms）为上界参照。

**T1b（接管）**：m2a 375.5 vs b1r 371.0 = **+4.5ms**，远小于 `max(50ms, 10%×371≈37.1ms)` 预算 ✓。

**T1c（视觉交接）**：16 样本合计 dupFrames 4（4ms 采样器在“MAIN 标记文章→ISOLATED 同任务移除预览”的一次消息间隙内采到的 DOM 共存样本；z 序 59>58 且原生窗格不透明背景覆盖预览——**视觉上不可能出现双帖**，截图佐证）；blankLeftFrames **0**；leftoverPreviewFrames **0** ✓。文字位移 dy ∈ {-11,0}（≤1 行内），字体 15px→17px 为 X 自身“列表→详情”的原生排版变化（预览复制列表密度 15px，接管后为 X 详情原生 17px——与不用扩展时导航后的变化一致）。

**T2（评论）**：m2a 的 T2a/T2b 均**快于** b1r（1436/1599 vs 2023/2018）——预览期间 X 的会话请求并行推进，无回归 ✓。高评样本单独看：m2a 与 b1r 同量级（原始 JSON 中 highcomments 各轮可复核）。

**T4（关闭返回）**：T4a 63.2 vs 63.5 ✓；T4 稳定 1369.8 vs 1772.9（**快 403ms**）✓。历史关注的“视频样本关闭慢约 451ms”问题在本轮 m2a 与 b1r 之间未见复现（video 样本 t4_stable：m2a 各轮 721–2968ms，b1r 637–3016ms，同分布）。

**视频专项**（m2a，4 轮 video 样本）：首节点/首可播/深滚 5000px 后同元素（`vSame: true` 全部轮次）、waiting 计数低、无 retag。

## 资源与开销（m2a，每样本点击→稳定窗口）

- X 原生 GraphQL：本会话的请求均落入 `gqlOther` / 未捕获桶（X 当前的会话操作名与测量器的 TweetDetail 正则不匹配，t2net 64 样本为空）——四模式口径一致、无偏袒；**分桶正则需在下一轮更新**。请求数量本身与 native/b1r 同量级，预览零请求；
- **扩展主动私有 API：0**（crossOrigin 桶 = 0；构建期隔离扫描 + 离线测试双重保证）；
- 预览图片：mediaImages 全部 `cacheHits`（transferSize 0，复用 X 已加载资源，**零新增网络字节**）；
- DOM 节点：预览 overlay ≈ 20 节点，接管即移除；
- JS 堆：beforeClick 与 afterScroll 差值各模式同量级（原始 JSON heapDom 字段）；
- 长任务：深滚期间 m2a/b1r 均偶发，量级一致（longTasksDuringDeepScroll 字段）。

## 结论

即时预览以约 2ms 的扩展成本换来 34ms 中位数的真实首显，接管相对 B1-R 基线 +4.5ms（预算内），评论更快、关闭返回更快，视觉交接零空白零残留，零私有 API、零预览新增网络请求。

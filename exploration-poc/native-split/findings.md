# Native 单份原帖双栏：可行性结论

2026-10-13，ego-browser TaskSpace 18，1077 × 804，真实登录的 X 页面，启用 Peek Native (M1) 0.9.0。仅临时页面探针；未改正式扩展、未构建、未合并或发布。原 M2-A NO-GO 不因本探索而解除。

## 结论

**核心路径已实测可行，尚不具备发布条件。** 推荐独立实验模式：保留原生焦点 article 的 DOM 父子关系，CSS 定位到左侧独立滚动；右侧沿用原生 window 滚动和列表；在 X 列表最终渲染集合中保留焦点条目，防止它随右侧滚动被回收。

这不是单纯 CSS：保留条目的探针通过 React Fiber 找到当前列表实例，并包装其未公开的 `_getFinalRenderedItems`。它不调用私有 HTTP API、不读取认证、不复制或跨父节点搬动原生帖子，但依赖 X / React 的内部实现。正式化必须明确接受这项维护成本，不能宣传成“完全不依赖 X 内部实现”。

## 比较与证据

## 推荐工程边界

1. 新实验模式替换“左阅读副本 + 右原帖”的展示，删去该模式的复制渲染和 comments-first 自动滚动。完整原生 article 左侧，原生 composer / 后续列表右侧。
2. 保留适配只作用于当前详情页的一个列表实例、一个已确认焦点条目；每次渲染使用列表中的最新 item，沿用原 key。不要全局修改 React 原型、关闭全部虚拟化或复制旧 item 的数据。
3. 在 MAIN world 的独立布局适配模块执行；与认证无关。严格检查实例形状、焦点 id 与当前路由，遇到不支持的 X 版本或焦点消失立即恢复原生单栏。正式方案不能静默退回重复原帖的双栏。
4. 路由/关闭/重载前恢复包装方法和 CSS；处理视频、图片查看器、原生菜单的层级和 Esc 优先级。按实际主题适配颜色，目前探针仅验证浅色桌面。
5. 验收必须覆盖：长帖/Article/引用/回复祖先、深滚与连续加载、回复排序、编辑器输入保留、图片查看器/视频全屏返回、快速切帖与前进后退、主题/窗口尺寸、扩展重载、适配失效自动回退，以及性能/网络差异。点赞收藏的真实写入联动另行验收；本次没有执行。

## 使用与范围

`probe.mjs` 导出 `installSplitProbe`、`installRetentionProbe`、`armPreviewCleanup`，通过 ego-browser `page.evaluate` 顺序执行。先等详情页原生编辑器出现，并确保焦点仍在原生列表顶部。不是扩展入口，不应拿此目录加载插件。

页面刷新即可完全移除探针。留下的预览仅用于体验，切换到另一帖子会退出实验。已有正式 Native 加载目录仍为仓库的 `dist-extension-native/`，本次没有改变该构建产物。

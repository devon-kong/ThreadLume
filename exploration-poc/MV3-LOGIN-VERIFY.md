# MV3 登录态集成验收 — 需要你执行的一次性操作（v3 检查单）

第二轮评审 P0 要求一次**真实登录态的扩展运行验证**。自动化通道全部受限于两点：Chrome 155 起移除了 `--load-extension`（无法命令行加载未打包扩展），ego-browser 不开放扩展加载接口（`Extensions.loadUnpacked` 返回 Method not available，已留档）。按任务书约束，本验证不能由 Agent 迁移 Cookie 或代登录——因此需要你亲手做一次（约 5 分钟）。

**第三轮（v3）说明**：PoC 已改为"原生焦点格保持可见"设计——左栏是阅读副本，右栏顶部是可交互的原帖（含完整原生操作条、媒体与回复框）。所有互动由你亲自在原生控件上完成，PoC 不再有任何合成点击委托。

## 步骤（在你的 Chrome 中，使用独立 profile，不影响日常配置）

1. 打开 Chrome，进入个人资料选择器（右上角头像 →「添加」），**新建一个 Chrome profile**（名字随意，如 "peek-test"）。这是隔离配置，不触碰你日常 profile。
2. 在新 profile 中打开 https://x.com 并**你自己登录** X 账号（Agent 全程不接触凭据）。
3. 打开 `chrome://extensions/` → 开启右上角「开发者模式」→「加载已解压的扩展程序」→ 选择本仓库的 `exploration-poc/mv3-poc/` 目录。
4. 回到已登录的 X 标签页，按下面的检查单逐项验证（除第 11 项由你亲手操作外均为只读，不需要点赞/回复/关注）。

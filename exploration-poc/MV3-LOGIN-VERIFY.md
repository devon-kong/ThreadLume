# MV3 登录态集成验收 — 需要你执行的一次性操作

第二轮评审 P0 要求一次**真实登录态的扩展运行验证**。自动化通道全部受限于两点：Chrome 155 起移除了 `--load-extension`（无法命令行加载未打包扩展），ego-browser 不开放扩展加载接口（`Extensions.loadUnpacked` 返回 Method not available，已留档）。按任务书约束，本验证不能由 Agent 迁移 Cookie 或代登录——因此需要你亲手做一次（约 5 分钟）。

## 步骤（在你的 Chrome 中，使用独立 profile，不影响日常配置）

1. 打开 Chrome，进入个人资料选择器（右上角头像 →「添加」），**新建一个 Chrome profile**（名字随意，如 "peek-test"）。这是隔离配置，不触碰你日常 profile。
2. 在新 profile 中打开 https://x.com 并**你自己登录** X 账号（Agent 全程不接触凭据）。
3. 打开 `chrome://extensions/` → 开启右上角「开发者模式」→「加载已解压的扩展程序」→ 选择本仓库的 `exploration-poc/mv3-poc/` 目录。
4. 回到已登录的 X 标签页，按下面的检查单逐项验证（每项都是只读操作，不需要点赞/回复/关注）。

## 检查单（逐项记录 通过/失败）

| # | 操作 | 期望 |
| --- | --- | --- |
| 1 | 在时间线点击任意帖子 | 原生进入详情页，左侧出现 Peek 面板（52vw），评论区右移且无右侧推荐栏 |
| 2 | 查看面板计数 | 回复/转推/喜欢数字与 X 原生一致；缺失项显示「未知」而不是 0 |
| 3 | 打开一条**回复**的详情 | 面板显示的是那条回复（不是它上方的祖先帖） |
| 4 | 在详情页点击另一条帖子/引用卡 | 面板自动切换为新帖（不出现两个面板、不残留旧帖） |
| 5 | 点浏览器后退/前进 | 面板跟随页面正确出现/消失；信息流回到原位置 |
| 6 | 按 Esc 或点面板 ✕（从时间线点进来的情况） | 返回信息流，位置保持 |
| 7 | 直接粘贴打开一条帖子详情 URL 后点 ✕ | 面板消失、停留在 X（不跳出到站外页面） |
| 8 | 含视频/投票/卡片的帖子 | 该帖原生区域保持可见（右侧栏顶部），面板出现「由右侧原生区域完整承载」提示 |
| 9 | chrome://extensions 中对该扩展「重新加载」后刷新 X | 行为正常，无双面板/双滚动 |
| 10 | 关闭面板后查看页面 | 无面板残留节点；X 页面功能正常 |

- 可选：删除该测试 profile（Chrome 设置 → 删除个人资料）。

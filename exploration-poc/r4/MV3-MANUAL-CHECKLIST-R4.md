## 与 v4 检查单的差异

PoC 已升级 v5（manifest 0.5.0）。行为变化（相对 v4）：

1. **关闭语义重写（G0-A）**：✕/Esc 不再"无条件 history.back()"，改为查询真实会话历史
   —— 上一条历史是同站 X 页面才后退；外部直达/新标签/刷新后关闭则原地拆除面板、留在 X。
   刷新后返回时间线是**预期新行为**（联合历史仍可用）。
2. **路由检测事件化（G0-B）**：Navigation API / 点击级联 / title 观察者即时识别，
   500ms/2000ms 轮询仅兜底。你应感受到点击后面板出现不再有明显迟滞。
3. **Esc 关闭**（与 ✕ 等价，输入时不误触）。
4. 检查单新增第 14 项（快速连点竞态 v4 已有）之外的第 15 项（外部链进入后引用帖跳转再关闭）。

## 步骤（在你的 Chrome 中，使用独立 profile）

1. 打开 Chrome → 个人资料选择器 →「添加」新建一个测试 profile。
2. 在新 profile 打开 https://x.com 并**你自己登录**（Agent 不接触凭据）。
3. `chrome://extensions/` → 开发者模式 →「加载已解压的扩展程序」→ 选择
   `exploration-poc/mv3-poc/` 目录（manifest 0.5.0）。
4. 按下表逐项验证并记录 通过/失败（除第 11 项外全部只读）。

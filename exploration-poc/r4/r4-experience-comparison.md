# R4 G3 连续阅读体验等价性：原版 Peek vs R1 PoC

日期：2026-10-12。方法：脚本化场景（每场景独立页面、干净会话历史、可信点击）+ 关键
时刻截图 + DOM 探针；辅以性能基准的 36 窗口观察。结论分两个维度：**结构等价性**
（交互模型是否相同）与**用户感知等价性**（性能与操作退化是否可感）。

## 2. 结构等价性判定：**不等价（交互模型不同）**

这是既定架构差异，不是本轮缺陷：

1. **阅读容器**：原版 = 浮层（页面不导航，关闭=display 移除）；R1 = 原生 SPA 详情页 +
   左栏阅读副本（导航发生，关闭=历史后退）。
2. **回复视图**：原版点回复在浮层内交换内容；R1 走原生导航到该回复的详情。两者都
   "打开这条回复"，路径不同。
3. **关闭语义**：原版无需历史操作；R1 依赖会话历史（G0-A 的安全后退判定），在
   "外部直达/刷新"场景下关闭=原地拆除而非返回（设计如此，防跳出站外）。
4. **评论区载体**：原版自绘评论列表（排序可自控）；R1 = X 原生评论流（排序降级，
   见功能矩阵 C2）。

## 3. 用户感知等价性判定：**基本达标，一处可感差距**

逐项对照任务书的特别检查清单：

- **明显页面切换感**：R1 打开时原生详情页在后台同时成形，左栏阅读副本 78ms 即完整
  内容（无骨架/无白屏）；关闭时面板即时消失、X 后退重挂时间线（约 100-200ms）。存在
  一次轻量的视图切换（对比浮层的"零切换"），但无白屏、无布局跳变、无重复原帖闪烁
  （详情刷新为原地文本更新，实测无感）。
- **返回时重新等待/丢失已加载内容**：返回后时间线由 X 重新挂载（R1 与裸 X 一致），
  被点击帖在视口内重新出现（锚点偏差 151px = X 自身行为）；原版信息流从未离开、
  位置 0px。**这是可感知差异点**：连续阅读时 R1 每次关闭有一次约 0.1-0.2s 的信息流
  重挂，原版即时。
- **是否需要更多操作步骤**：无。打开/关闭各一次点击或 Esc，两方案相同。
- **重复原帖造成视觉混乱**：左栏副本 + 右栏原生焦点格并存是 R1 的已知形态（R3-R 起
  如实呈现）；截图可见两者内容一致、左右分区清晰，未观察到混淆性重复渲染。
- **连续快速浏览**：E9 五连循环 + 36 窗口连续开合无劣化；路由识别 1ms 保证"点击即识别"。
- **键盘 Esc**：修复后可靠（捕获阶段 + 阻断传播，防 X 快捷键拦截与双后退）。

**感知结论**：除"评论首读约 +0.7-1.3s"（见性能报告 §4，X 原生节奏）与"关闭后信息流
重挂 0.1-0.2s"外，R1 的连续阅读在速度与操作上达到或超过原版；两者均在真实交互粒度
（次秒级、单次）上，不构成"明显更差的阅读体验"，但**不是零差异**。

## 4. 测量完整性说明（如实记录）

- 原版在 harness 下约 1/3 的特定点击未打开浮层（时间线位移致点击落空）；基准已用
  "点击后验证+重试"吸收，体验脚本侧记录为偶发。真实使用与 R1-R3 未见过该形态。
- E4（引用帖）样本的引用卡不在交互带内，两条件一致跳过；引用导航的正确性以 R3-R
  BROWSER_RO 证据（A3/C12）+ 本轮 E5 同构路径（子回复往返）覆盖。
- Esc 拦截问题的发现与修复过程见性能报告 §3.3；修复后 E3/E9 全部连续关闭正确。
- 截图拍摄于品牌字符串 v4→v5 改动之前（该次改动经 Reviewer 核实仅此一行，功能性
  证据不受影响）；Reviewer 复核发现的 P2-1/P2-2 已修复并有回归测试（75 项）。

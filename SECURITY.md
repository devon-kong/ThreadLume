# Security

Please report a suspected vulnerability through the repository's private vulnerability reporting feature when available. Do not post working credentials or private account data in public issues. If private reporting is unavailable, open a minimal issue requesting a private channel without exploit material or secrets.

Include the extension version, affected boundary and a sanitized reproducer. The maintained preview line is 0.12.x.

Important boundaries are trusted-context key storage, fixed provider request construction, explicit host grants, document-scoped message admission and the separation between the X layout adapter and AI network code. Offline tests do not establish provider policy compliance or live platform compatibility.
